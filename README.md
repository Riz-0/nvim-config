# Introduction

Welcome to my personal neovim configuration! [Neovim](https://neovim.io) is a fork of Vim, a popular terminal-based text editor, focused on extensibility and usability. This repo serves as backup for my configuration files as well as a way for me to practice my git and documentation skills.

# Installation

```
cd $HOME/.config
git clone git@github.com:Riz-0/nvim-config.git nvim
```
